The project focused on developing machine learning (ML) frameworks for network anomaly detection using network-specific, locally sourced data. My primary contribution involved the ML component of the project.
Owing to the confidential nature of the project and restrictions on disclosing proprietary company information, only non-sensitive materials relevant to my individual contributions have been made available in this repository. Furthermore, due to the security-sensitive nature of the network data, I have refrained from sharing the underlying datasets. Consequently, the results section has been limited to a brief overview for the same security reasons. three overview images of the core project have been included to provide context and facilitate a clearer understanding of the work undertaken.
